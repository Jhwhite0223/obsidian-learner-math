# obsidian-learner-math

A Chinese-language Codex skill for processing calculus classroom notes, evening-study questions, examples, images, and PDFs in an Obsidian vault.

## Install

Copy this directory into your Codex skills directory as `obsidian-learner-math`.
Set the active Obsidian vault root in the skill and `references/vault-contract.md` for your own machine.

The repository contains no API keys, access tokens, credentials, or machine-specific runtime state.
